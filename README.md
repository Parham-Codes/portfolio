## Features

- **Atmospheric Dark Glass Aesthetics**: Deep slate-black canvas with luminous cyan, indigo, and emerald ambient light fields.
- **Dynamic Scrollspy Navigation**: Responsive navigation pill with smooth scrolling and active section awareness.
- **Flagship Project Showcases**: Case study cards with window controls, key architectural wins checklist, telemetry badges, and interactive preview modals.
- **Categorized Technical Repertoire**: 3-tier skill breakdown with visual proficiency meters and real-world competency descriptions.
- **Career Path Chronicle**: Glowing milestone timeline detailing commercial React engineering experience.
- **Interactive Contact Hub**: One-click email copy with visual feedback, availability indicators, and direct message dispatch form.
